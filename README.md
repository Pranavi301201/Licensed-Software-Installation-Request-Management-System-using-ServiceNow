# Software Installation Request Automation – ServiceNow

## 📌 Project Overview

The **Software Installation Request Automation** project is a ServiceNow-based application designed to streamline the process of requesting, approving, and fulfilling software installations within an organization.

Traditionally, software installation requests may be handled through emails or manual communication, which can lead to delays, lack of visibility, and communication issues.

This project automates the complete workflow using the **Service Catalog, Flow Designer, Business Rules, and custom table functions**.

---

## 🎯 Objectives

* Automate software installation requests
* Reduce manual communication and processing time
* Provide an approval-based workflow

## 🔄 Project Workflow

The overall process works as follows:

1. Employee logs into the ServiceNow instance.
2. Employee navigates to the **Service Catalog**.
3. The employee opens the **Software Installation Request** catalog item.
4. Required details such as software name, version, license type, and installation device are entered.
5. Business justification and user eligibility are validated.
6. The system checks software license availability.
7. The request is submitted through the Service Catalog.
8. The request is automatically routed to the appropriate manager or software owner for approval.
9. Approvers receive an automated notification.
10. Once approved, a fulfillment task is automatically created for the IT support team.
11. The IT team installs the requested software and updates the task status.
12. The system updates the request status to **Completed**.
13. The employee receives a confirmation notification.
14. Requests, approvals, and installations are tracked for auditing and reporting.

## 📋 Key Features

### Software Installation Request

Employees can submit software installation requests through the Service Catalog by providing the required information.

### License Validation

The system dynamically validates software license availability before processing the request.

### Automated Approval

Requests are automatically routed to the appropriate approver based on predefined conditions.

### Automated Fulfillment

After approval, fulfillment tasks are automatically generated for the IT support team.

### Notifications

Automated notifications keep employees and approvers informed about request progress and approval status.

### Request Tracking

The complete lifecycle of the request can be tracked from submission to completion.
